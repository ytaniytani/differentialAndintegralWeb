# ライティング&レンダリングで体感する微分・積分

トーンカーブ・ノーマルマップ・ブルーム・ソフトシャドウ・ボリュームフォグ・自動露出——
TA / ライティングアーティストが毎日触っているパラメータの「数学的な正体」を、
スライダーを動かしながら体感するインタラクティブな学習ページです。

**必要な数学は中学まで。** 準備編(傾き・面積)から★4の挑戦編まで、易しい順に9つのデモが並びます。

公開ページ: https://ytaniytani.github.io/differentialAndintegralWeb/

## 見方・動かし方

ビルド不要の静的サイトです。

```bash
# ローカルで見る(ES Modules のためHTTPサーバー経由で)
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages(main ブランチ / ルート)でそのまま公開できます。

## 構成

| セクション | 題材 | 学ぶこと |
|---|---|---|
| P1 ★1 | ライトのフェードイン | 微分=グラフの各点での傾き |
| P2 ★1 | カメラの露出 | 積分=細かく刻んで足す(面積) |
| §1 ★2 | トーンカーブ | コントラスト=カーブの傾き |
| §2 ★2 | ノーマルマップ | 法線=ハイトの傾き |
| §3 ★2 | アウトライン抽出 | エッジ=隣のピクセルとの差 |
| §4 ★3 | ガウシアンブラーとブルーム | 畳み込み=重み付きの積分 |
| §5 ★3 | エリアライトのソフトシャドウ | モンテカルロ=ランダムに試して足す |
| §6 ★3 | ボリュームフォグ | レイマーチング=レイに沿った数値積分 |
| §7 ★4 | 自動露出とフレーム蓄積 | 時間方向の微積分(Δt・TAA的蓄積) |

## 技術

- HTML + CSS + Vanilla JavaScript(ES Modules)。外部ライブラリゼロ
- 描画はすべて Canvas 2D。重いピクセル処理は低解像度オフスクリーンで計算して拡大表示
- 画面外のデモは IntersectionObserver で自動停止

詳細な設計は [SPEC.md](SPEC.md) を参照してください。
